# REWARDNEXT — Rewards Program Analytics (Power BI)

## Overview
An interactive Power BI dashboard built to analyze campaign performance, customer engagement, and offer completion trends for the **REWARDNEXT** rewards program.

## Dashboard Preview
![REWARDNEXT Performance Dashboard](performance-dashboard.png)

## Key Metrics (KPIs)
- **Total Revenue:** ₹1.78M
- **Offers Received:** 76K
- **Offers Completed:** 34K
- **Completion Rate:** 44.02%

## Key Insights & Visuals Covered
- **Offer Performance by Event Type:** Comparison of total offers received vs. offers completed across offer categories (`discount`, `bogo`, `informational`).
- **Customer Demographics:** Breakdown of customer distribution and engagement across segments.
- **Offers Completed vs. Viewed:** Tracking offer conversion and completion funnel (`34K` completed).
- **Interactive Slicers:** Filter by **Gender**, **Offer Type**, and **Age Group** for targeted analysis.
